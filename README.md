# D Studio – Design Agency Website

## 1. Project Overview

D Studio is a modern and responsive creative agency website built to showcase the agency's design services, portfolio, and contact information.

The website focuses on a clean, minimal, and professional user interface with interactive elements, smooth transitions, and a user-friendly experience.

## 2. Tech Stack Used

- **Next.js** – React framework for building the website.
- **React.js** – For creating reusable and interactive UI components.
- **JavaScript** – For implementing functionality and form handling.
- **Tailwind CSS** – For styling, layouts, and responsive design.
- **Lucide React** – For modern and consistent icons.
- **Git & GitHub** – For version control and source code management.

## 3. Features

- **Responsive Design:** Layout designed to work across different screen sizes.
- **Interactive Navigation:** Navigation links for easy access to different sections.
- **Hero Section:** Introduces the agency with a modern design and call-to-action buttons.
- **Services Section:** Displays the creative services offered by the agency.
- **Portfolio Section:** Showcases selected projects and creative work.
- **Contact Section:** Allows visitors to submit enquiries through a contact form.
- **Hover Effects:** Interactive hover effects on buttons, links, and other UI elements.
- **Smooth Transitions:** CSS transitions for a more engaging user experience.
- **Icon Integration:** Lucide React icons used to enhance the visual appearance.
- **Basic Form Validation:** Validates required fields and checks email format before submission.
- **Reusable Components:** Website sections are organized into reusable React components.

## 4. Setup Instructions

### Prerequisites

- Node.js installed
- npm package manager
- Git (optional)

### Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/Jeni-Ignatio/D--Studio-homepage-.git
```

**Step 2: Navigate to the project directory**

```bash
cd D--Studio-homepage-
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm run dev
```

**Step 5: Open in browser**

Visit [http://localhost:3000](http://localhost:3000)

## 5. Assumptions

- D Studio is a fictional creative agency created for this project.
- The website is primarily intended to showcase agency services and portfolio work.
- Sample content is used for demonstration purposes.
- Images are sourced from Pexels and used as visual assets.
- The contact form performs basic client-side validation.
- The website is designed to support desktop, tablet, and mobile devices.
- The project is a frontend-focused implementation and does not currently include a backend for storing contact form submissions.
